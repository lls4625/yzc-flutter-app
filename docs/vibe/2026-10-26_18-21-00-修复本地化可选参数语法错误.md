# 修复本地化可选参数语法错误

## 问题分析

Xcode 在 Flutter iOS 打包阶段报告 `lib/l10n/l10n.dart:48:15: Error: Expected ')' before this.`。问题位于 `localizedText` 函数新增的韩语可选位置参数声明，不涉及 Xcode 工程配置或 iOS 构建脚本。

## 修改前

`localizedText` 的参数列表将必填参数 `String ja` 单独以逗号结束，随后又声明 `[String? ko]`，并在可选参数组的右方括号后保留逗号：

```dart
String ja,
[String? ko],
```

这种写法不符合 Dart 的可选位置参数语法，解析器在 `[` 处期待参数列表已经以 `)` 结束。

## 修改后

将可选位置参数组接在前一个必填参数之后，并采用项目中已有的多行写法：

```dart
String ja, [
String? ko,
])
```

## 修改内容与原因

- 仅调整 `lib/l10n/l10n.dart` 中 `localizedText` 的参数列表标点和分组。
- 保留 `ko` 的可空类型、调用方式和韩语回退逻辑不变。
- 修复 Dart 解析错误，使编译器能够正确识别新增的韩语可选位置参数。

## 可能影响与注意事项

- 此修改不改变函数的参数顺序或运行时行为。
- 现有未传入 `ko` 参数的调用仍使用默认的 `null`，韩语界面继续回退到 `localizedKoreanInlineText(zhHans, en)`。
- 按项目约定，本次未执行构建、编译、格式化检查或自动化测试；需要由维护者手动重新构建确认。
