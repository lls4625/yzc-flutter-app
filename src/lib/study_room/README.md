# 自习室代码目录

每个学习模块独立管理功能与演示代码。项目根目录 `AGENTS.md` 的“功能代码与演示代码严格隔离”为全局强制约束；以下目录说明不得被理解为允许两者共用业务实现。

```text
study_room/
├── listening/       # 磨耳朵
│   ├── entry.dart   # 宿主入口：分别打开功能或演示
│   ├── feature/
│   └── demo/
├── dictation/       # 听写
│   ├── feature/
│   └── demo/
├── flashcards/      # 闪卡
│   ├── entry.dart   # 宿主入口：分别打开功能或演示
│   ├── feature/
│   └── demo/
├── jlpt_practice/   # JLPT练习
│   ├── entry.dart   # 宿主入口：分别打开功能或演示
│   ├── feature/
│   └── demo/
├── jlpt_test/       # JLPT测试
│   ├── entry.dart   # 宿主入口：分别打开功能或演示
│   ├── feature/
│   └── demo/
├── home/            # 自习室首页及模块入口编排
├── access/          # 自习室权限与购买接入
├── host_contracts.dart
└── study_room_module.dart
```

- `feature/`：正式功能入口、功能页面、业务控制及正式数据存储，不包含演示模式。
- `demo/`：独立演示入口、页面、组件、模型、控制器、样例数据读取、自动引导和内存存储。
- 功能与演示不互相 import、export、part、调用或继承，也不得通过公共目录共用页面、业务组件、模型、控制器和存储接口。需要相似行为时保留独立副本，允许演示落后于正式功能。
- 同时提供功能和演示按钮的宿主入口必须位于两者目录之外，只负责选择并打开独立入口。
- 闪卡已经采用上述隔离结构：演示不接收正式宿主对象，不读取正式内容目录或学习记录；自动演示停留统一为2.5秒。
- 磨耳朵已移除 feature/demo 的 Dart part 关系和页面复用，外层 entry.dart 分别打开独立入口。演示自有 page、scaffold、controller、models、text、样例读取和 guide，不接收正式宿主、权限或内容对象。演示以当前课程排序页和播放页为独立快照，每步自动停留 2.5 秒后推进，播放阶段音频持续循环；保留暂停、下一步、跳过和重播。系统减少动态效果或辅助导航开启时，初始暂停，可手动继续。
- 闪卡和磨耳朵均继续使用既有通用玻璃 UI 与 NativeAudioTransport 底层音频设施；两侧业务代码独立，并非复制整个 Flutter 框架和底层音频引擎。演示使用独立音频身份并在退出时停止自己持有的音频。
- 听写的入口路由已迁移到 `dictation/entry.dart`，由宿主分别打开正式听写与独立演示提示；正式 `feature/` 不再引用演示入口。这是听写范围内的迁移，不代表全项目隔离审查完成。
- 听写、JLPT练习、JLPT测试尚未实现的演示保留原提示，入口在各自 `demo/entry.dart`。
- 公共演示 JSON、音频统一放在 `assets/demos/` 并随 App 打包；不按功能复制资源。磨耳朵与闪卡各自的演示代码读取同一份资源，演示不要求付费或安装正式内容。
- `home`、`access` 和宿主契约属于自习室基础代码，不属于学习功能的演示。

- JLPT练习和JLPT测试已各自实现正式功能，卡片路由迁至各自外层 entry.dart。两个 feature/ 各自持有页面、模型、资源读取、作答、结果与独立 SQLite 存储，不互相引用，也不引用 demo/。演示仍保留原有独立提示。
- JLPT 正式题库通过自习资源服务下载并导入本地数据库，首次使用需下载资源，下载后可离线使用；App 不内置 assets/study/jlpt 题库副本。首次作答冻结题目，暂停续做读取本模块自己的会话。
- JLPT 合成朗读仅调用现有通用原生语音通道，各自维护请求身份和停止生命周期，不引入旧练习页面或业务模型。
